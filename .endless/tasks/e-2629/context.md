Two packages hold their own copy of the same block-summary types. gomion's gomtui has CondensedBlock and FileCondensedDiff in context_info_pane_model.go, built by BuildCondensedDiff from gomion's internal gitutils.FileChanges. go-tealeaves' teadiff copied CondensedBlock, FileDiff and FileStatus into teadiff/types.go. The builder reads only old and new lines plus each change's type and line ranges, which DiffContent already carries, and it uses neither git nor a TUI, so go-diffutils is its home. go-gitutil's FileChanges.ToDiffContent already converts to DiffContent. A go-gitutil planning document (PLAN-CONDENSED-DIFF-TYPES.md, removed by go-gitutil's release task) had proposed go-gitutil as the home.
