Decided with Mike on 2026-11-16, in go-gitutil E-2624's session: the type is named ChangeBlockSummary because 'Condensed' did not say what the type represents. go-diffutils adds no per-file wrapper: teadiff keeps FileDiff (path, status, blocks) as its render input, since DiffContent's Label already carries the path and status is a rendering concern. The behaviour to carry over from gomtui's BuildCondensedDiff: added blocks read NewLines over NewRange and deleted blocks read OldLines over OldRange; up to 2 context lines before and after; all changed lines when there are 5 or fewer, otherwise the first 3 with the truncated flag set.
